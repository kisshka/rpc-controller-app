# Система контроля и управления доступом
Работа разделена на две части: веб-клиент, с помощью которого пользователь осуществляет управление доступом и создание библиотеки классов, позволяющей взаимодействовать с контроллером доступа С2000-2 через «Интегрированную систему охраны Орион».
Взаимодействие с контроллером доступа осуществляется с помощью технологии XML-RPC.

Работа выполнена в рамках производственной практики на предприятии "ЭлРос"
